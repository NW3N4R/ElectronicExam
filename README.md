# ElectronicExam

A C# desktop application that digitizes the exam process — giving administrators full control over exam creation and management, while providing examiners a clean interface to conduct and oversee exams.

---

# Features

- **Admin Panel** — Create, edit, and manage exams, questions, and users
- **Examiner Interface** — Conduct exams and review results in a dedicated environment
- **Role-based access** — Separate workflows for administrators and examiners
- **Built with C#** — Solid, structured, and easy to extend
